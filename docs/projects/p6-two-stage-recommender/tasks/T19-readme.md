# T19: Project README

**Phase:** 6 Write-up · **Estimate:** 1.5 h · **Depends on:** T12, T13, T14, T16, T17, T18

## Ask

Write the project README, leading with the result.

## Why

The README is what most readers will see; every project leads with one chart plus three bullets.

## How

- Order: headline chart (e.g. NDCG@k by model, overall vs cold-start) + three bullets answering the
  headline questions → architecture diagram → metrics table → feedback-loop summary → design
  decisions → reproduce → data and licence → limitations.
- Tick every item on the `docs/conventions.md` README checklist.

## Plan

- [ ] Architecture diagram
- [ ] Remaining sections
- [ ] Follow the reproduce section from a clean clone

## Acceptance criteria
