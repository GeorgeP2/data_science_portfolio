# T05: Confirm how the LCL trial assigned households

**Phase:** 1 Elasticity · **Estimate:** 1 h · **Depends on:** none

## Ask

Find out from the LCL trial documentation how households were assigned to ToU vs standard tariff,
and decide whether elasticities can be called causal.

## Why

The brief lists this as the top risk. If assignment wasn't randomised, every elasticity claim must be
worded as associational, and the write-up changes.

## How

- Read the LCL trial reports (UK Power Networks / Imperial) on recruitment and assignment.
- Record: randomised or not, opt-in or not, any pre-trial baseline period, known imbalances.

## Plan

- [ ] Find the primary source on assignment
- [ ] Write a short note in `results/lcl-trial-design.md` with citations
- [ ] Decide causal vs associational wording and record it

## Acceptance criteria

- [ ] Note cites the source document and page/section
- [ ] States clearly whether elasticities will be reported as causal or associational
